# Instrucciones para Agentes IA

## Comandos Principales
- Build: `npm run build`
- Tests: `pytest`
- Lint: `ruff check`

## Estilo de Código
- Usa black para formateo.
- Siempre añade tests.

## Límites

- Al finalizar tarea, actualiza context/05-tasks.md
